## 3. 네이버 연동 조사 결과 (공식 사이트 직접 접근 불가 → 2차 자료 기준, 원문 미확인)
### 3-1. 계정 연결·열람 권한 위임
- GSC식 "사용자 추가/권한 위임" 기능 근거 **없음**. 네이버 로그인 OAuth 범위에 서치어드바이저 데이터 없음.
- 가능성 있는 방식: 서비스 측 네이버 계정으로 사용자 사이트 등록 → 사용자가 서비스용 소유확인 메타태그 설치(비밀번호 수집 X). **동일 사이트 다중 계정 소유확인 가능 여부는 미확인** → 계정 2개로 직접 테스트 필요. 소유확인 1년마다 갱신.
### 3-2. 자동 로그인·크롤링
- 네이버 이용약관은 "자동화된 프로그램 등을 이용한 게시물 등의 무단 수집" 금지(2차 자료), 위반 시 민사책임 가능.
- 위임 계정이라도 자동 로그인 후 리포트 수집은 해당 조항에 걸림 + 캡차/보안 확인으로 운영 불안정 → **브라우저 자동수집 PoC는 하지 않는 것으로 권고**(서면 예외 허용 없으면 상용 불가).
### 3-3. 이전 제안 정정
- "네이버 검색 API(웹문서)로 색인 여부 확인" 제안 → **2026-09-07 시행 검색 API 특약 개정**(보도 기준)으로 어려움: 네이버 검색결과 제공 목적으로만 이용, 서버 보관 최대 21일, API HUB(네이버클라우드) 이관 중·개발자센터 신규 신청 중단.
### 3-4. 약관 문제 없는 네이버 기능 (1단계 현실적 범위)
- IndexNow URL 제출(네이버 공식 지원), 사이트맵·robots·메타태그 점검, 리포트 수동 입력/파일 업로드(다운로드 기능 존재 여부 미확인), 서치어드바이저 바로가기.
- 결론: 현재 네이버 통계 자동수집은 불가, 1단계 네이버 기능은 "제출·점검" 수준 → 이 범위로 지불의사 있는지 인터뷰로 검증.

## 9. 2026-11-16 GA4 API 검토 (2·3단계 후보, 미결정)
- GA4는 공식 API 있음: **Data API**(보고서·실시간·퍼널 조회), **Admin API**(속성·스트림·주요 이벤트 관리, `accountSummaries.list`로 사용자 속성 목록), **Measurement Protocol**(서버에서 이벤트 전송), BigQuery 내보내기(원시 이벤트).
- 인증: Google OAuth `analytics.readonly` → 1단계 Google 로그인에 권한 범위만 추가하면 GSC와 함께 연동 가능. 무료, 속성별 토큰 할당량.
- 의미: 2단계 방문·전환 추적을 자체 스크립트 없이 시작 가능. GEO·네이버의 사이트 쪽 측정(AI 유입, `search.naver.com` 유입 × 방문 페이지)도 GA4 API로 매일 자동 조회 가능. 수집봇 방문(Yeti, GPTBot 등)은 GA4에 안 잡혀 서버 로그 필요.
- GEO 측정 참고: Bing 웹마스터 AI Performance(2026-02 공개 미리보기)가 Copilot 인용 수·페이지·grounding query 제공.

## 10. 2026-11-16 비개발자 온보딩 검토 (미결정)
- 비개발자는 대부분 사이트 빌더(아임웹·카페24·식스샵·Wix·워드프레스 등)의 SEO 설정 칸에 소유확인 메타태그를 붙여넣는 방식. Google은 GA4 태그·DNS로도 소유확인 가능.
- 우리는 소유확인을 대신 못 함(이미 등록된 사이트를 API로 읽는 구조) → 등록 안내 필요. **IndexNow 키 파일은 빌더에서 루트 업로드가 안 될 수 있음** → 기획안 v1.3 0단계·10장에 "빌더별 소유확인 메뉴·IndexNow 키 파일 지원 여부 조사" 추가.
- 다른 프로젝트의 제품 투어·AI 안내문 사례 참고(개념만):
  - 투어: driver.js, 버튼으로만 시작, 상태 저장 없음, 행동을 시작하는 화면에서 끝냄.
  - AI 안내문: 서버 LLM 호출 없이 문구 생성 → 사용자가 복사해 자기 AI에 붙여넣음. "지금 제 상태"(끝낸 단계) 미리 넣기가 효과 최대, AI가 사용 패턴을 먼저 묻게 함, 버튼명 "AI용 안내문 복사", 키는 AI에 붙여넣지 말라는 경고.
- 사용자가 말한 "제품 투어"는 **Search Console 등 외부 사이트 등록 가이드**였음.
- **결정(2026-11-17):** 1단계에 **엔진별 등록 가이드 + 연동 체크리스트 + 단계별 "AI용 안내문 복사"**, 우리 화면 투어는 제외. 분석용 AI 안내문(노출 많고 클릭 적은 검색어 개선 등)은 2단계 이후.
  - 가이드 순서: ① GSC(URL 접두어 방식, GA4 있으면 GA로 소유확인, 없으면 HTML 태그, 사이트맵 제출, 서비스에서 Google 로그인) → ② Bing(**GSC에서 가져오기**로 소유확인 생략, API 키 발급) → ③ 네이버(HTML 태그, 사이트맵, 서비스엔 주소만 → 리포트 링크 자동).
  - 스크린샷은 최소(외부 UI가 자주 바뀜), 공식 도움말 링크 위주.
